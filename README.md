# Vocalist Sim

2D-симулятор становления вокалистом. Глубина симуляции — от Kairosoft,
перемещение и социальные связи — от Gameloft Nights.

Сейчас в работе **вертикальный срез**: один район, 60 игровых дней,
путь от самоучки до первого платного концерта в клубе.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер Vite (слушает сеть — можно открыть с телефона) |
| `npm run build` | Типы + продакшен-сборка |
| `npm test` | Юнит-тесты ядра (Vitest) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint, включая правило изоляции `core/` |
| `npm run check` | typecheck + lint + тесты |
| `npm run play:text` | Текстовый прогон 60 дней в консоли |
| `npm run sim` | Headless-симулятор баланса на 1000 партий |

## Архитектура

```
src/
  core/       чистая симуляция. НОЛЬ импортов из phaser/game/ui/platform
    state/    GameState, редьюсер, экшены
    systems/  time, vocal, money, fame, relations, events, career
    rng/      сидированный ГПСЧ
    types/
  data/       декларативный контент, валидируется Zod
  game/       Phaser: сцены, спрайты, камера, тайлмапы
  ui/         экраны интерфейса
  platform/   SaveAdapter, InputController, конфиг
  sim/        headless-симулятор для баланса
```

Три правила, которые проверяет линтер и которые нельзя нарушать:

1. `core/` не импортирует `phaser`, `game/`, `ui/`, `platform/`, `sim/`.
2. `Math.random()` запрещён везде — только сидированный ГПСЧ из `core/rng`.
3. Ввод идёт только через `InputController`; клавиатуру напрямую никто не читает.

Внутреннее разрешение фиксировано **480×270**. Зум целочисленный, пока
округление вниз стоит меньше 20% экрана (десктоп: ×2, ×3, ×4), и дробный,
когда целое отняло бы заметную долю — иначе телефон в ландшафте получал
×1 и треть площади. На узком экране в портрете игра просит повернуть
телефон: 16:9 туда читаемо не помещается.

Интерфейс собран на примитивах Phaser, а не на DOM-элементах: DOM не
участвует в целочисленном зуме и требовал бы знания о реальном размере
окна, что запрещено. Весь ввод — тапы и клавиши — проходит через
`Hotspots`, который следит и за минимальным размером области тапа.
Всё, что делается с клавиатуры, обязано быть доступно тапом — это условие
переноса на Tauri и Capacitor.

## Текстовый прогон

```
npm run play:text -- --strategy=support --seed=vocalist-01 --genre=pop
```

Стратегии: `support` (сначала опора), `gigs` (берёт все концерты),
`money` (не тратит ни рубля), `random` (контрольная группа).
Один сид даёт один и тот же прогон.

## Баланс

```
npm run sim -- --runs=1000 --genre=pop
```

Прогоняет каждую стратегию на тысяче сидов и печатает: долю дошедших до
клубного концерта, медианы денег, славы и здоровья связок, частоту травм
и долю слотов у самого частого действия.

Главная проверка — правило раздела 10 мастер-документа: если «берёт все
концерты» обыгрывает «сначала опора», неверны цифры, а не стратегия.
Текущее состояние: опора доводит до клуба ~70% партий, «все концерты» —
0% при 4.5 травмах за партию.
