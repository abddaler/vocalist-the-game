# Vocalist Sim

2D-симулятор становления вокалистом. Глубина симуляции — от Kairosoft,
перемещение и социальные связи — от Gameloft Nights.

Сейчас в работе **вертикальный срез**: один район, 60 игровых дней,
путь от самоучки до первого платного концерта в клубе.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер Vite |
| `npm run build` | Типы + продакшен-сборка |
| `npm test` | Юнит-тесты ядра (Vitest) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint, включая правило изоляции `core/` |
| `npm run check` | typecheck + lint + тесты |
| `npm run play:text` | Текстовый прогон 60 дней в консоли |
| `npm run sim` | Headless-симулятор баланса на 1000 партий (веха 3) |

## Архитектура

```
src/
  core/       чистая симуляция. НОЛЬ импортов из phaser/game/ui/platform
    state/    GameState, редьюсер, экшены
    systems/  time, vocal, money, fame, relations, events, career
    rng/      сидированный ГПСЧ
    types/
  data/       декларативный контент, валидируется Zod
  game/       Phaser: сцены, спрайты, камера, тайлмапы
  ui/         экраны интерфейса
  platform/   SaveAdapter, InputController, конфиг
  sim/        headless-симулятор для баланса
```

Три правила, которые проверяет линтер и которые нельзя нарушать:

1. `core/` не импортирует `phaser`, `game/`, `ui/`, `platform/`, `sim/`.
2. `Math.random()` запрещён везде — только сидированный ГПСЧ из `core/rng`.
3. Ввод идёт только через `InputController`; клавиатуру напрямую никто не читает.

Внутреннее разрешение фиксировано **480×270** и масштабируется целочисленно:
дробный зум мылит пиксели, поэтому поля по краям оформлены как рамка.
Всё, что делается с клавиатуры, обязано быть доступно тапом — это условие
переноса на Tauri и Capacitor.

## Текстовый прогон

```
npm run play:text -- --strategy=support --seed=vocalist-01 --genre=pop
```

Стратегии: `support` (сначала опора), `gigs` (берёт все смены),
`money` (не тратит ни рубля). Один сид даёт один и тот же прогон.
