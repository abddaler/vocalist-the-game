# Ревью локаций: нормы, автопроверка и промпт для визуального разбора

> Часть А — промпт для визуального ревью, вставлять вместе со скриншотом.
> Часть Б — нормы, на которые он опирается. Часть В — автопроверка.
> Часть Г — самопроверка художника до сдачи.

Документ — источник порогов для `npm run audit:locations`. Числа из части Б
живут в `src/data/balance.ts` (раздел `scenery`); менять их нужно там, а
здесь править описание.

## ЧАСТЬ А. Промпт визуального ревью

Копировать целиком, приложить скриншот локации в нативном разрешении
(480×270) и второй с масштабом 1:1 без интерполяции.

```
Ты — арт-директор проекта. Перед тобой скриншот локации из
изометрической 2D-игры про карьеру вокалиста. Стиль — пиксель-арт,
изометрия 2:1, внутреннее разрешение 480×270.

Локация: [название]
Назначение по геймдизайну: [что игрок здесь делает, какие действия]
Интерактивные объекты по спецификации: [список]
Целевая плотность: [из норм]

Проведи разбор строго по разделам ниже. Не хвали. Не смягчай.
Каждая находка привязана к конкретному месту на изображении и
содержит конкретное указание, что сделать.

1. УЗНАВАЕМОСТЬ ПРЕДМЕТОВ
Перечисли все предметы. Для каждого укажи, что это, по твоему
мнению, и насколько ты уверен. Отдельно выпиши те, которые не смог
опознать за две секунды или опознал неверно. Это главный дефект:
если предмет непонятен тебе, он непонятен игроку.

2. ЛИШНЕЕ
Найди предметы, которые не участвуют ни в одном действии, ничего не
рассказывают о месте и никак не связаны с его назначением. Такие
предметы удаляются, а не переделываются.

3. ПЛОТНОСТЬ И ПУСТОТА
Раздели пол на четверти. Для каждой оцени заполненность. Отдельно:
мёртвые зоны (пустой пол больше 4×4, через который не ходят),
заторы (проходы уже 2 тайлов), «стена из мебели» (три и более
крупных объекта подряд без просвета).

4. ПОВТОРЫ
Одинаковые спрайты в одном кадре, с количеством. Отдельно —
регулярные ряды с одинаковым шагом. Это самый заметный признак
непроработанной сцены.

5. КОМПОЗИЦИЯ
Есть ли смысловой центр? Не прижато ли всё к стенам с пустым
центром («зал ожидания»)? Есть ли объекты в воздухе, врезающиеся в
стену, стоящие вполтайла?

6. ТЕХНИЧЕСКИЕ ОШИБКИ
Нарушения изометрии; свет не сверху-слева; неверный масштаб
относительно персонажа; швы и стыки тайлов, разрывы стен, дыры в
полу; заметное повторение текстуры пола; пропущенные тени.

7. ЦВЕТ
Доминирующая температура сцены. Объекты вне палитры. Отделяется ли
персонаж от фона по светлоте в любой точке локации.

8. КАЧЕСТВО ОТРИСОВКИ
Предметы, отрисованные заметно грубее: меньше тонов, нет обводки,
плоская заливка, «шум» вместо текстуры.

ИТОГ
Таблица: место — что не так — критичность (блокер / серьёзно /
мелочь) — что конкретно сделать. Отсортировать по критичности.
Вердикт одним словом: ПРИНЯТО / ДОРАБОТКА / ПЕРЕДЕЛКА.
Любой блокер — не ниже ДОРАБОТКИ. Три и более блокеров — ПЕРЕДЕЛКА.
```

## ЧАСТЬ Б. Нормы

Без этих цифр ревью превращается в спор о вкусах.

### Б.1 Плотность

Заполненность — доля площади пола, занятая объектами.

| Тип локации | Заполненность | Ширина проходов |
|---|---|---|
| Квартира | 45–60% | не менее 2 тайлов |
| Ресторан | 50–65% | 2 тайла между столами |
| Клуб | 35–50% (танцпол пуст намеренно) | 3 тайла |
| Репбаза | 55–70% | 2 тайла |
| Студия звукозаписи | 60–75% | 2 тайла |
| Магазин одежды | 50–65% | 2 тайла |
| Спортзал | 55–70% | 2 тайла между тренажёрами |
| Кабинет фониатра | 40–55% | 2 тайла |
| Улица района | 30–45% | 3 тайла |

Ниже нижней границы сцена читается недоделанной. Выше верхней игрок не
может пройти и не понимает, куда смотреть.

**Пустота бывает намеренной.** Танцпол, сцена, коридор пусты по функции.
Мёртвая зона — пустота, через которую игрок не ходит и на которую не
смотрит. Различать обязательно.

### Б.2 Повторы

- Один спрайт в кадре — **не более 3 раз** без вариации.
- Вариация — смена оттенка, отражение, поворот на другое направление,
  накладной декор (полотенце на тренажёре, стакан на столе).
- Ряды одинаковых предметов с равным шагом запрещены. Ломать ритм:
  смещение, поворот, пропуск, другой предмет в ряду.
- Тайл пола — минимум 4 варианта на материал, распределение случайное с
  преобладанием базового 70%.

### Б.3 Масштаб относительно персонажа (40 px фигуры)

| Предмет | Высота, px |
|---|---|
| Стул | 20–24 |
| Стол | 18–22 |
| Барная стойка | 26–30 |
| Дверь | 48–56 |
| Дорожка беговая | 44–50 |
| Стойка микрофонная | 38–42 |
| Диван | 22–26 |
| Холодильник | 40–46 |
| Колонка концертная | 44–52 |

Ошибка масштаба разрушает сцену сильнее, чем плохой рисунок.

### Б.4 Оправданность предмета

Каждый объект обязан пройти хотя бы одну проверку:

1. **Функция** — с ним взаимодействуют, он привязан к действию.
2. **Характер** — он говорит что-то о месте или его владельце.
3. **Композиция** — направляет взгляд, заполняет провал, ломает повтор.

Не прошёл ни одну — удалить. Не переделывать, не улучшать. Удалить.

### Б.5 Узнаваемость

Каждый предмет рисуется с фотореференса, не по памяти. Узнаваемый силуэт
делает работу, а не детали.

Проверка: показать спрайт человеку вне контекста, вырезанным из сцены.
Назвал за две секунды — принят. Не назвал — переделка силуэта, а не
добавление деталей. Деталей на 32 пикселях не видно, силуэт виден всегда.

### Б.6 Стены

- Голая стена длиннее 6 тайлов подряд — дефект.
- Наполнение: плакаты, окна, зеркала, полки, трубы, кабели, розетки,
  трещины.
- Наполнение стен не считается в заполненность пола.

## ЧАСТЬ В. Автопроверка

`npm run audit:locations` проходит по всем локациям без графики и
браузера и выдаёт таблицу `локация / правило / объект / значение / норма
/ критичность`. Код возврата ненулевой при блокерах.

Всё, что можно проверить машиной, не должно попадать в визуальный ревью.
Глаза дороги, тратить их на подсчёт одинаковых стульев нельзя.

Состояние проверок — в `src/sim/audit/`. Там же перечислено, чего разбор
не покрывает и почему.

## ЧАСТЬ Г. Самопроверка перед сдачей

Пять тестов, каждый на минуту.

**Тест силуэта.** Залить всё чёрным. Предметы должны различаться по
контуру. Слились — переделка формы.

**Тест прищура.** Размыть скриншот. Должны остаться 2–3 крупных пятна —
смысловые центры. Ровная каша означает, что композиции нет.

**Тест незнакомца.** Показать локацию человеку вне проекта. Спросить: что
это за место и что здесь можно делать. Не ответил — сцена не работает,
сколько бы в ней ни было деталей.

**Тест персонажа.** Поставить спрайт игрока в восемь разных точек. Везде
должен быть виден. Пропал на тёмном ковре — менять фон, не персонажа.

**Тест удаления.** Убрать по очереди каждый предмет и посмотреть, стало
ли хуже. Не стало — предмет не нужен.
